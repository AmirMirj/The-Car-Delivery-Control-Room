# Quickstart: AI Build Judgement

## Prerequisites

App running (`npm run dev` in `starter/`).

## Validate

1. Open http://localhost:3000 — home is still **Needs a person**.
2. In the sidebar, open **Build notes**.
3. Confirm four sections and that each has concrete build examples.
4. Confirm no network call to an LLM (static page; DevTools optional).

```sh
cd starter && npm run typecheck
```
