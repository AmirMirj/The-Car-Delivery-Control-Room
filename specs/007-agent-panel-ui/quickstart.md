# Quickstart: On-road Agent Panel Concise UI

## Prerequisites

- App running (`starter/`: `npm run dev`).
- Order that qualifies for on-road agent with a **pending** proposal.

## Validate

1. Open the order → Agent panel below Timeline.
2. Header is one short policy line (not a paragraph essay).
3. Findings show as a few bullets; full handoff only after expand.
4. Decision text appears **once** on the approval card (not also as “Proposed decision” + giant chat paste).
5. Approve / Reject still work; Run again still works; chat Send still works.
6. Long chat messages truncate with Show more.
7. Visual style remains birch/ops.
