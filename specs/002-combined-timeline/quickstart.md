# Quickstart: Combined Order Timeline

## Prerequisites

Starter running (see `starter/README.md`); snapshot seeded.

## Validate

1. Open http://localhost:3000 and pick an exception order.
2. Confirm **Timeline** appears with pills and “Combined view · full details remain below”.
3. Default pill is **Needs attention** when the order has attention items.
4. Click **Everything**, **Conversations**, **Agent work**, **Activity** — list and header count update; pill counts stay fixed.
5. Scroll down — Conversations / Prior agent work / Activity (or folds) still present.

## Expected

Ops-readable combined feed without losing deeper sections.
